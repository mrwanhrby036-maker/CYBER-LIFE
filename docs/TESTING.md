# الاختبارات

## التشغيل

```bash
./scripts/run_tests.sh
```

أو يدويًا:

```bash
cd backend && python -m pytest tests -q
cd tests-frontend && npm install && npm test
python scripts/count_lines.py
```

## التغطية الحالية

### Backend (pytest)

- الصحة والمصادقة المحلية، رفض رموز غير صالحة.
- المنهج: 15 فصلًا، 45 درسًا، 6 مختبرات، ≥50 مصطلحًا، عدم تسريب مفاتيح.
- التقدم: تمرين خاطئ 422، إكمال صحيح، تقييم فصل.
- الفرق: إنشاء مرة واحدة، اسم مكرر 409، زملاء ومساهمات.
- المهام: دورة كاملة `mis01` حتى `closed`، بوابات المراحل، جمع أدلة، قرارات، تقرير.
- المختبر: أوامر مسموحة، رفض أوامر خطرة 422، `grep -c Failed auth.log` = 4، تحقق تمارين.
- الأدمن: 403 للطالب، نشر/إلغاء، إنشاء محتوى، منع خفض دور النفس، سجل تدقيق.
- الأمان: قواعد RTDB، إعدادات إنتاج fail-closed، تطبيع إجابات عربية، تصحيح rubric.

### Frontend (node:test + jsdom)

- صفحات HTML عربية RTL ومواردها موجودة.
- روابط التنقل تغطي الصفحات المطلوبة.
- CSS يحتوي نقاط توقف للموبايل.
- `escapeHtml` يمنع الحقن.
- تحقق النماذج (required/min/email/json).
- عميل API يضيف Bearer ويفسر الأخطاء.
- حارس الأدمن موجود.
- المختبر لا يستخدم eval/subprocess.

## قيود الاختبار

- لا توجد اعتمادات Firebase في هذه البيئة؛ تدفق Google وقواعد RTDB الحية لم تُختبر end-to-end.
- اختبارات الواجهة unit/static وليست متصفحًا حقيقيًا؛ يوصى بإضافة Playwright لاحقًا.
- تحذير Starlette حول httpx غير مؤثر على النتائج.
