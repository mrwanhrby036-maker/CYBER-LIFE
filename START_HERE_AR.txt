  CYBER LIFE — منصة تعلّم الأمن السيبراني
  ابدأ من هنا
═══════════════════════════════════════════════════

هذا الملف المضغوط يحتوي على المشروع كاملًا ونظيفًا.
لا يوجد فيه أي كلمة مرور أو مفتاح سرّي.


───────────────────────────────────────────────────
١) ماذا يوجد بالداخل؟
───────────────────────────────────────────────────

  frontend/     واجهة المنصة — ١٢ صفحة
  backend/      الخادم الخلفي — Python FastAPI
  content/      ١٥ فصلًا دراسيًا + المهام + المعمل
  database/     قواعد حماية قاعدة البيانات
  docs/         كل الأدلة (اقرأ README_AR.md أولًا)
  scripts/      أدوات التشغيل والاختبار والرفع
  tests-frontend/  اختبارات الواجهة
  vercel.json   إعداد النشر على Vercel
  firebase.json إعداد نشر قواعد Firebase


───────────────────────────────────────────────────
٢) النشر على الإنترنت — ٣ خطوات
───────────────────────────────────────────────────

الخطوة الأولى: GitHub
  المستودع موجود بالفعل:
     https://github.com/mrwanhrby036-maker/CYBER-LIFE
  لكنه فارغ — لازم ترفع الملفات إليه.

  الطريقة الأولى (الأسهل — Windows):
    ١. فك ضغط هذا الملف في مجلد
    ٢. افتح المجلد، ثم scripts
    ٣. اضغط يمين على  push_to_github.ps1
    ٤. اختر  Run with PowerShell
    ٥. سجّل الدخول إلى GitHub لو طُلب منك

  الطريقة الثانية (Mac / Linux):
    bash scripts/push_to_github.sh mrwanhrby036-maker

  الطريقة الثالثة (بدون تثبيت أي برنامج):
    ١. افتح https://github.com/mrwanhrby036-maker/CYBER-LIFE
    ٢. اضغط  "uploading an existing file"
    ٣. اسحب كل محتويات المجلد وأفلتها في الصفحة
       (اسحب ما بداخل المجلد، لا المجلد نفسه)
    ٤. اضغط  Commit changes

الخطوة الثانية: Vercel
  تم بالفعل — المشروع منشأ ومربوط بالمستودع:
     الاسم: cyber-life
     مجلد الإخراج: frontend
     الفرع: main

  بعد رفع الملفات سيُنشر تلقائيًا، أو أبلغ المساعد لينشره.
  الرابط المتوقع:  https://cyber-life.vercel.app

الخطوة الثالثة: Firebase  ← لا تتخطّاها
  ١. افتح  https://console.firebase.google.com
  ٢. اختر مشروع  hamo-8132e
  ٣. Authentication ← Settings ← Authorized domains
  ٤. Add domain ← اكتب رابط Vercel بتاعك ← Save

  بدون هذه الخطوة تسجيل الدخول لن يعمل.


───────────────────────────────────────────────────
٣) تشغيل المنصة على جهازك (اختياري)
───────────────────────────────────────────────────

  تحتاج Python 3.11 أو أحدث.

  cd backend
  python -m venv .venv

  على Windows:
     .venv\Scripts\activate
  على Mac / Linux:
     source .venv/bin/activate

  pip install -r requirements.txt
  cd ..
  bash scripts/serve_preview.sh

  ثم افتح  http://localhost:8000

  بيانات الدخول التجريبية تُطبع في نافذة الأوامر فقط،
  وتُحفظ في  backend/.data/preview-credentials.json
  وهي بيانات مؤقتة لجهازك أنت، لا تصلح للإنترنت.


───────────────────────────────────────────────────
٤) تشغيل الاختبارات (اختياري)
───────────────────────────────────────────────────

  الاختبارات ليست مضمّنة الحزم الجاهزة، ثبّتها أولًا:

     cd backend
     pip install -r requirements.txt
     python -m pytest -q

     cd ../tests-frontend
     npm install
     node --test

  المتوقع: ٥١ اختبارًا للخادم + ١٥ للواجهة = ٦٦ ناجحة.
  تم التحقق من ذلك على نسخة مفكوكة من هذا الملف المضغوط.


───────────────────────────────────────────────────
٥) ما يعمل الآن وما يحتاج إعدادًا
───────────────────────────────────────────────────

  يعمل فورًا بعد النشر:
    ✓ الصفحة الرئيسية وكل صفحات العرض
    ✓ إنشاء حساب وتسجيل الدخول (بعد خطوة Firebase)

  يحتاج استضافة الخادم الخلفي:
    ○ الدروس والمهام والتقدّم والنتائج
    ○ لوحة تحكّم المشرف

  الخادم يحتاج ملف service account من Firebase.
  هذا الملف سرّي: لا ترفعه على GitHub ولا ترسله في محادثة.
  ضعه على الاستضافة كمتغيّر بيئة فقط.

  التفاصيل كاملة في  docs/GITHUB_AND_VERCEL.md


───────────────────────────────────────────────────
٦) حالة المشروع
───────────────────────────────────────────────────

  الاختبارات: ٦٦ ناجحة (٥١ للخادم + ١٥ للواجهة)
  الفصول: ١٥ فصلًا، ٤٥ درسًا، ١٥ مهمة، ٦ معامل
  Firebase: مُعدّ ومُتحقّق منه فعليًا

  اقرأ docs/IMPLEMENTATION_STATUS.md لقائمة صريحة
  بما اكتمل وما تبقّى.
